
# Diabetes Progression Prediction

## About the Project
This is my beginner Machine Learning project using Python and Scikit-learn.

The project uses the built-in Diabetes dataset to train a Linear Regression model and predict a numerical measure of disease progression.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn

## What I Learned
- Loading datasets using Scikit-learn
- Splitting data into training and testing sets
- Training a Linear Regression model
- Making predictions
- Evaluating predictions using Mean Squared Error (MSE)
- Understanding model coefficients and intercept

## How to Run

Install the required libraries:

```bash
pip install numpy matplotlib scikit-learn
```

Run the Python file:

```bash
python main.py
```

## Model Evaluation
The model is evaluated using Mean Squared Error (MSE) on the test dataset.

## Disclaimer
This project is for educational purposes only. It is not a medical diagnostic tool.
